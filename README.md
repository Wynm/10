# مختبر الوكلاء — Open Agent Workbench

واجهة ويب عربية لتجربة فرق وكلاء محليين باستخدام Ollama، مع موصل PubNub اختياري للرسائل الفورية وموصل REST قابل للضبط لـ Blocks.ai. الواجهة تنسّق الوكلاء بالتتابع؛ مخرجات كل وكيل تظهر للفريق، ويُنشر كل رد إلى قناة PubNub عند تفعيل المفاتيح.

## التشغيل محليًا

المتطلبات: Node.js 20+، و[Ollama](https://ollama.com/) مع نموذج مثبت (مثل `ollama pull qwen2.5:3b`).

```sh
npm install
npm run dev
```

افتح العنوان الذي يعرضه Vite (عادة `http://localhost:5173`). يُفترض أن يستمع Ollama على `http://localhost:11434`. لتغيير العنوان: `OLLAMA_HOST=http://... npm run dev`.

في الإنتاج: `npm run build` ثم `NODE_ENV=production npm start` (الخادم على المنفذ 3000 افتراضيًا، ويمكن تغييره عبر `PORT`).

## التكاملات

- **Ollama:** اتصال من الخادم إلى واجهة Ollama. النماذج تعمل على جهازك؛ يلزم إبقاء الجهاز والخادم قيد التشغيل.
- **PubNub:** أدخل Publish وSubscribe keys في «إعداد التكاملات». النشر يتم على الخادم إلى قناة `agent-lab`. مفاتيح PubNub المدخلة في الواجهة تبقى في ذاكرة الخادم فقط حتى إعادة تشغيله. للإنتاج، استخدم صلاحيات/قنوات محدودة، ويفضل إدارة الأسرار من متغيرات بيئة أو مخزن أسرار موثوق.
- **Blocks.ai:** الموصل يرسل طلب POST من الخادم إلى عنوان API الأساسي والمسار القابلين للضبط، مع جسم `{task, agents, messages}` ورأس Bearer اختياري. يجب إدخال **صيغة عنوان ومسار وطلب متوافقة مع توثيق Blocks.ai الفعلي**. لا يمكن تأكيد التوافق مع واجهة الحساب من دون توثيق API أو بيانات اعتماد/تفاصيل endpoint؛ لا يُفترض أن `/api/agents/run` endpoint حقيقي.
- **GitHub:** الواجهة جاهزة كنقطة بداية للتجارب؛ استيراد المستودعات وتنفيذ الشيفرة غير مفعّلين بعد. لا تشغّل شيفرة مستودعات غير موثوقة على خادم الإنتاج.

## ملاحظات قبل النشر

هذا نموذج أولي، وليس خدمة إنتاجية متعددة المستخدمين. الإعدادات مؤقتة في الذاكرة، ولا توجد مصادقة أو حفظ مشاريع أو ضوابط حصص. لا تنشره مكشوفًا على الإنترنت قبل إضافة المصادقة، تقييد CORS/الطلبات، إدارة الأسرار، وحماية إساءة الاستخدام. الخطة المجانية قد تفرض حدودًا أو تتغير؛ لا يمكن ضمان خدمة مجانية بلا انقطاع. التشغيل المحلي بـ Ollama يقلل الاعتماد على رسوم API لكنه يتطلب جهازًا وطاقة واتصالًا مستمرًا للتكاملات السحابية.
